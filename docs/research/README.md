# ELOS scientific evidence register

This directory records the evidence used by the V1 pedagogical policy. It contains metadata and
original summaries only. It does not store copyrighted papers or learner data.

- `evidence-index.json` is the machine-readable source register.
- `SCIENTIFIC_PEDAGOGY_V1.md` records the six decisions, product mapping, limits and metrics.

Evidence labels follow the programme hierarchy: `LEVEL_A` for systematic reviews and
meta-analyses, `LEVEL_B` for large controlled studies, `LEVEL_C` for individual peer-reviewed
studies, `LEVEL_D` for preprints, and `LEVEL_E` for conceptual claims. A technical publication
about an algorithm does not by itself establish learning effectiveness for ELOS learners.

The retrieval date is `2026-09-14`. Before changing a scientific decision, verify the DOI,
publication status, legal URL, study population and fit with the current product.
